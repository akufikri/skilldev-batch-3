STEP BUILD BACKEND :

1. Buat middleware untuk menjaga (input nilai, log aplikasi/history)
2. Membuat DTO(Data Transafer Object) untuk menjaga nilai yang masuk/validasi input value
3. Kita membuat service untuk menentukan Logic bisnis pada backend kita (ex: CRUD PRODUCT)
4. Kita membuat controller untuk RestAPI (ex: CRUD PRODUCT)
5. Kita buat module untuk menggabungkan Controller dengan Service agar bisa di akses
